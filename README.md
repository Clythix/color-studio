# Clythix // Professional Color Suite 🎨

Clythix is a lightning-fast, feature-rich web application built for designers and developers to create, explore, extract, and check color palettes with ease.

## ✨ Features

- **Palette Generator:** Generate harmonious color schemes instantly using the spacebar, lock colors you like, and view corresponding shades and tints.
- **Multiple Color Formats:** Toggle color values between HEX, RGB, and HSL formats on the fly.
- **Advanced Export:** Export palettes cleanly as CSS variables, Tailwind CSS configuration, or JSON.
- **Saved Vault:** Bookmark and store your favorite generated color schemes locally in your browser.
- **Explore Slider:** Browse through an endless stream of curated color palettes with forward and backward history navigation.
- **Image Color Extractor:** Upload any PNG or JPG to automatically extract dominant color palettes.
- **Accessibility Contrast Checker:** Calculate WCAG contrast ratios to ensure text and background compliance.

## 🚀 Tech Stack
- Pure HTML5 / CSS3 / Vanilla JavaScript
- FontAwesome Icons
- Google Fonts (Plus Jakarta Sans & Space Mono)

## 📦 Usage
Simply open `index.html` in any modern web browser to launch the suite!
